# Student Management System — Future Labs Africa

A beginner-friendly, multi-page assignment project built with vanilla HTML, CSS and JavaScript.

## Run it
1. Extract the ZIP.
2. Open `student-management-system/index.html` in a browser.
3. Register a few students and test search, filtering, sorting, editing and deletion.

No server, framework, external library, database, localStorage or sessionStorage is used.

## Important before submission
- The assignment requires you to understand and explain your implementation. Read `js/script.js` carefully and practise explaining the array of student objects, DOM updates, events, validation and statistics.
- The team profiles, contact details, course durations and fees are sample placeholders. Replace them with verified details or clearly label them as demonstration content.
- Student records intentionally exist only in memory and reset when the page is refreshed, as required by the brief.
- Contact form validation is client-side only; it does not send a message to a backend.
